How It Works

Two clicks to connect. No signup, no terminal, no config.

1

Host Starts Sharing

Opens QuickDesk → Share My Screen → Start. Gets a local address + a random PIN.

2

Enable Worldwide Tunnel

Clicks Enable Tunnel — Cloudflare generates a public address like abc.trycloudflare.com. Works everywhere.

3

Share Address + PIN

Sends the address and 6-char PIN via WhatsApp, Telegram, or any chat app.

4

Viewer Connects

Pastes address + PIN → Connect. Sees the remote screen with full control.
